# Input Files

Photochem uses readable text and YAML files to describe model configuration and data. The v1.0 input reference will document:

- reaction mechanisms;
- Photochem settings;
- Clima species and settings;
- stellar flux files;
- atmosphere profiles; and
- Equilibrate species files.

Atmosphere profiles preserve pressure-temperature-composition and eddy-diffusion profiles, but they are not complete model reinitialization files and do not retain every setting.
