# Installation

The complete installation guide will be written in a later documentation pass. Photochem can currently be installed from conda-forge:

```sh
conda install -c conda-forge photochem
```

After installation, verify that Python can import the package:

```sh
python -c "import photochem; print(photochem.__version__)"
```

The finished guide will cover supported platforms, environment setup, package data, troubleshooting, and building from source.
